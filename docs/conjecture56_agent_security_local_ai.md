# Conjecture 56 — Sistemas de agentes seguros y eficientes

- **Tipo:** Línea de investigación aplicada seleccionada
- **Nombre de trabajo:** C56 Agent Systems Lab
- **Disciplinas principales:** Informática e inteligencia artificial

## 1. Elección

Conjecture 56 combinará dos líneas inicialmente propuestas:

- **C56 Agent Security Lab:** investigar cómo desplegar y operar agentes de inteligencia artificial con controles efectivos de seguridad, permisos, trazabilidad y supervisión.
- **C56 Efficient Local AI:** investigar cómo ejecutar modelos de inteligencia artificial eficientemente sobre recursos propios o alquilados, con atención a rendimiento, costos, confiabilidad y control de los datos.

La combinación puede desarrollarse bajo el nombre de trabajo **C56 Agent Systems Lab**, sin que este nombre implique todavía una marca o unidad organizativa formal.

**Propósito:** investigar, desarrollar y evaluar arquitecturas que permitan a organizaciones utilizar agentes de IA de forma **segura, controlable y económicamente eficiente**, eligiendo racionalmente entre servicios comerciales y modelos ejecutados en infraestructura propia o en la nube.
